# Day8-3 Frontend Evidence & Recommendation Integration

This is a presentation-only integration over Day8-2.

The frontend consumes:
- reason_text / reason_tags
- constraint_evidence
- matched_constraints / unmatched_constraints
- matched_count / constraint_count
- retrieval_sources
- citation_path

It does not recompute relevance, regenerate recommendation reasons, or invent citation paths.
